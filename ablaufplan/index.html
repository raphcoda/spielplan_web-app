Kurzinfo Ablaufplan

Drucken und PDF

  • Desktop, obere Zeile: druckt den Gesamtablaufplan mit Bühne, Tonregie und Technik.
  • Desktop, Drucker im Bereich Bühne/Tonregie/Technik: druckt nur diesen Bereich.
  • Handy: fragt vor dem Druck „Bereich oder Alles“.
  • Das PDF sollte zur Produktionsdokumentation auf dem Server abgelegt werden.

Bühnenplan (BP)

  • Desktop: Über den Knopf BP im Bereich Bühne einen Bühnenplan als PDF hochladen (max. 5 MB), ansehen, ersetzen oder entfernen.
  • Handy: Der Knopf BP erscheint im Bereich Bühne nur, wenn ein Bühnenplan hochgeladen wurde. Antippen öffnet den Plan.

Fotos (Kamera-Symbol, Bühne)

  • Grau = noch keine Fotos, grün = Fotos vorhanden. Bis zu 10 Fotos pro Produktion, jedes mit kurzer Beschriftung.
  • Handy: Antippen öffnet die Fotoliste mit „Foto machen“ und „Aus Gallery“. Desktop: Fotos auf das Kamera-Symbol ziehen oder anklicken. Der Dateiname wird als Beschriftung übernommen.
  • Im Vollbild: ⤓ lädt nur dieses Foto herunter, ↗ öffnet es in einem neuen Tab (dort zoomen).
  • „Alle herunterladen“ speichert alle Fotos als ZIP – zur Ablage auf dem Server.

Schloss

  • Mit dem Schloss neben der Produktion wird die ganze Produktion gesperrt.
  • Zum Entsperren braucht es den vierstelligen Code und das Namenskürzel.
